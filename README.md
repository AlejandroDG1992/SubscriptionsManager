# Subscription Manager

This is a project focused on subscription management, which allows users to have all their subscriptions located in one place so that they can see the information of each subscription without having to access their services.

## Technologies Used

- **Frontend**: React with Vite
- **Database**: Supabase
- **Authentication**: Supabase Auth

## Future Features

- Add, edit, and delete subscriptions.
- Organized view of subscriptions with direct links to services.
- Manage details such as pricing, renewal dates, and associated payment methods.
- Integration with Supabase for storage and authentication.
